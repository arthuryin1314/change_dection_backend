# 1a：分类结果契约与共享像元地表面积能力

## Parent

https://github.com/arthuryin1314/change_dection_backend/issues/6

## What to build

用户在现有识别页面执行识别后，继续看到色块，同时获得完整保存、可再次读取的空间分类结果。交付可程序化调用的识别与保存流程，以及后续矩阵和复用依赖的明确结果契约。本任务按用户要求聚焦存储契约，不包含分类面积列表。

## Acceptance criteria

- [ ] 整幅影像类别栅格与有效掩膜分开保存；有效背景属于类别 0，NoData 与未覆盖区不是类别 0。
- [ ] 分类体系固定六类编号与顺序为 0 其他／背景、1 水系、2 林地、3 道路、4 种植土地、5 房屋建筑；0 是六类之一，NoData 独立表达。矩阵行列严格按 0–5 排列。
- [ ] 本任务唯一负责交付后端像元到平方米的地表面积能力：基于 CRS、仿射变换及实际分辨率计算像元地表面积，经纬度使用大地面积方法；处理坐标单位及投影适用性，不能一律用仿射行列式或显示投影面积替代地表面积。
- [ ] 共享面积能力支持窗口／分块调用，供任务 1b、任务 2 和任务 3 直接使用；定义输入、输出单位、无效空间信息行为和数值容差依据。后续任务不复制算法或定义另一套容差口径。
- [ ] 本任务交付前以已知小栅格验证共享能力的米制与经纬度结果及分块一致性；任务 1b 负责完整分类统计的具名正确性验收，不能将本任务基础正确性留给后续才确认。
- [ ] 契约明确包含结果身份、所属用户、影像内容版本、模型权重内容版本、规范化推理参数及分类体系版本；替换影像或权重内容、改变影响推理的参数必须改变身份，显示单位和透明度不改变身份。
- [ ] 保存空间参考、仿射变换、实际推理宽高与分辨率、有效掩膜、类别栅格、完成状态和时间；可在不读取渲染图的情况下重建空间分类数据。
- [ ] 约定所有面积字段单位为平方米；完整分类结果的就绪条件独立于任务 1b 的面积汇总，不要求前端面积列表先完成。
- [ ] 识别与完整保存流程可被程序化调用，供任务 4b 使用；返回稳定结果标识，只有文件与记录完整可读才可标记成功，失败或半成品不可查询为可复用结果。
- [ ] 页面保留现有色块展示，可通过返回的结果标识重新读取结果；权限沿用当前用户边界。
- [ ] API 测试验证真实持久化后读取、不同身份输入、经纬度空间元数据往返、NoData 与背景区分、失败不可见及越权访问。
- [ ] 早期使用一景真实尺寸的代表影像测量识别与保存耗时、峰值内存，记录尺寸、分辨率、设备与读取限制；如无可用影像，明确标记未验证，不用小样本冒充。
- [ ] 完成项目必需检查，演示一次识别、保存、重新读取的完整路径。
