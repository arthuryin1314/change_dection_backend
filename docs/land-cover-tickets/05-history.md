# 5：识别与变化检测历史列表及结果查看

## Parent

https://github.com/arthuryin1314/change_dection_backend/issues/6

## What to build

用户从地物识别页面进入单期识别历史，打开已保存分类图及六类面积；从变化检测页面进入变化历史，查看矩阵及计算时上下文。刷新或重新进入后仍可查看，无需再次推理。用户已确认两类历史列表均包含在本版。

## Acceptance criteria

- [ ] 变化检测页面提供本人有权限的变化检测历史列表与详情，页面可打开矩阵、两期影像、模型版本、统计范围和计算时间。
- [ ] 历史详情将实际分析网格作为可选字段：存在时展示其坐标系、分辨率及网格信息，旧记录缺失时不报错、不伪造默认网格；验证字段存在与缺失两种响应。此兼容仅用于历史读取，不放宽新结果保存网格信息的要求。
- [ ] 地物识别页面提供用户可操作的历史列表入口，可选择记录打开分类色块、六类面积、单期影像、模型版本、范围及时间；不能仅用按 ID 查询接口代替页面入口。
- [ ] 历史显示计算时版本信息；后续影像或权重变化不得改写旧结果含义。
- [ ] 刷新后可重新打开结果，切换面积单位不触发推理或矩阵重算。
- [ ] 列表为空、详情不可访问和读取失败有明确反馈，不展示其他用户的结果或失败任务的半成品。
- [ ] 两类历史分别复用已有识别／矩阵展示和详情能力，不复制面积算法；本任务依赖任务 1b（#8） 的完整面积展示，统一默认公顷并调用同一单位换算能力。
- [ ] 隔离数据库和临时文件验证真实保存后历史读取与权限；前端会话测试验证历史打开及单位切换，页面验收刷新后的查看流程。
- [ ] 两类历史均通过刷新后读取、空列表、越权及详情失败测试。完成项目必需检查，不要求自动补算或不同网格能力先完成。

## Blocked by

- 任务 1b（#8）：六类面积统计与统一单位展示，供单期历史详情使用。
