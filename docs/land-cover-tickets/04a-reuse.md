## What to build

用户选择两期影像和模型，系统按 1a 的结果身份查找完整识别结果；两期均命中时直接进入既有矩阵流程，避免重新推理。本任务只交付复用，不编排缺失结果识别。

## Acceptance criteria

- [ ] 直接复用 1a 的结果身份契约，匹配用户权限、影像内容版本、模型权重内容版本、分析参数及分类体系版本，不新增不兼容的版本字段定义。
- [ ] 两期均命中完整结果时无推理调用，正常保存并显示矩阵；一方或双方缺失时明确返回缺失状态，为 4b 提供可区分的补算入口。
- [ ] 版本更新或参数变化不得命中旧结果；显示单位不影响命中。单期文件不完整、失败或权限不符不得作为命中。
- [ ] 页面表现为现有选择流程下的直接分析或明确缺失提示；任务 4b 完成后移除需要手动补齐的阶段性限制。
- [ ] API 验证双命中、单缺失、双缺失、内容版本变化、参数变化和越权；前端测试验证命中结果及缺失反馈。
- [ ] 完成项目必需检查，演示相同条件再次检测不会重新推理。
