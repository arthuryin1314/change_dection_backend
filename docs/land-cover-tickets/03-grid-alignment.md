# 3：不同坐标系与分辨率的影像自动对齐后分析

## Parent

https://github.com/arthuryin1314/change_dection_backend/issues/6

## What to build

用户沿用变化检测页面，直接比较已配准但坐标系、像素大小或网格原点不同的两期已识别影像。系统自动统一分析网格并展示、保存正确矩阵。

## Acceptance criteria

- [x] 移除同网格输入限制，使用确定的目标网格策略，记录分析空间参考、分辨率和变换信息。
- [x] 将任务 2 的 GRID_MISMATCH 从明确拒绝升级为自动统一网格，不改变其矩阵保存、公共有效区定义和空交集 NO_COMMON_VALID_AREA 行为。
- [x] 分类采用最近邻重采样，正确转换有效掩膜，只统计两期共同有效区域；不会因重采样生成不存在的类别。
- [x] 对统一后的网格调用任务 1a 的共享像元地表面积能力，沿用统一容差口径；不得直接复用重采样前像元面积或再实现另一套面积换算。
- [x] 网格策略避免把上采样当成精度提升，建议不细于两期较粗有效分辨率；实施中记录实际选择依据。
- [x] 页面明确要求影像已配准；不增加自动内容配准，也不要求覆盖范围完全相同。
- [x] 保存及详情读取包含实际分析网格，无有效重叠或空间元数据不可用时明确失败。
- [x] 从 API 入口以不同坐标系、分辨率和原点的小栅格验证真实空间计算，使用独立面积预期值与容差；演示页面对不同网格输入成功生成矩阵。
- [x] 完成项目必需检查。
- [x] 经用户批准，本任务已提前到 #11（自动补算）与 #12（历史）之前实施，以解除现有真实影像的异网格限制；不增加对 #11 或 #12 的阻塞依赖，硬依赖仍只有 #9。
