# 地物面积统计与变化矩阵方案

状态：需求访谈结论，2026-09-05。本文记录已确认需求及实现建议，尚未实施功能。

## 已确认的用户流程

1. 在地物识别页面选择影像和识别模型，点击识别，展示现有分类色块并保存识别结果；识别主页面不新增面积面板。
2. 在变化检测页面选择前后两期影像和一个识别模型，两侧自动关联已有结果并展示整幅有效区域六类面积；点击变化检测。系统复用符合所选模型版本的识别结果，自动识别并保存缺失的结果。
3. 系统统一两期分类结果的坐标系、像素大小和网格，在双方都有有效数据的重叠区域生成 6×6 地物类型转移面积矩阵。
4. 保存变化结果及两期影像、模型版本、统计范围和计算时间；页面提供历史入口，直接打开已保存结果。

## 统计定义与边界

- 六类为其他／背景、水系、林地、道路、种植土地、房屋建筑。实际类别编号和颜色须核对当前模型与前端映射，保持一致。
- 矩阵行是前期类别，列是后期类别。单元格表示对应类别转化面积，对角线表示类别未变面积。
- 单期面积统计整幅影像的有效区域；矩阵只统计两期共同有效的区域，因此矩阵行列合计不一定等于单期整幅面积。
- 未覆盖区域及 NoData 不属于其他／背景，不参与转移统计。无共同有效区域时，返回明确提示，不生成全零的成功矩阵。
- 后端按平方米计算和保存；前端默认公顷，支持平方米、平方公里。单位切换只改变展示。
- 首版输入影像须已配准。系统统一空间网格，但不自动纠正影像内容的位置偏移。

## 当前代码基础

- `router/segment.py` 的识别接口当前返回彩色 PNG 和 bbox，没有持久化分类面积。
- `utils/deeplab_service.py` 已提供逐像素类别掩膜推理与彩色渲染，可复用推理结果生成统计与展示。
- `utils/tif_reader.py` 读取影像窗口，可能限制大图读取尺寸；实施时需保留实际推理网格的空间变换及有效数据掩膜，不能用前端显示 PNG 的像素统计面积。
- 前端已有地物图例；`src/views/change/index.vue` 目前为功能开发中的占位页面。
- 现有 `DetectionTask` 模型可作为任务存储的检查起点；正式设计前核对关联结果表与数据库迁移约定，避免创建重复结构。

## 实现建议

以下为工程实现建议，不新增用户操作前置条件。

### 分类结果与保存

- 保留类别编号栅格、空间参考、像素网格及有效数据掩膜，另存分类面积与展示需要的结果。
- 图例勾选和透明度只影响显示；完整六类结果始终用于统计和后续矩阵计算。
- 记录影像版本、模型权重版本以及影响分类结果的推理配置；仅按模型 ID 匹配不足以防止权重替换后复用旧结果。
- 复用、读取和历史列表沿用用户权限边界。文件与数据库记录必须在完整成功后才标记可用，失败结果不能参与复用。

### 面积与变化计算

- 根据栅格空间参考计算真实地表面积；经纬度坐标不能直接把度数相乘当作平方米。
- 分类栅格对齐使用最近邻重采样，有效数据掩膜同步对齐；统一网格的选择保持确定并写入结果元数据。
- 默认建议采用不细于两期中较粗分辨率的分析网格，避免仅通过上采样造成精度提高的假象；实施时根据源数据和空间参考落实。
- 对共同有效像素累加前期类别到后期类别的面积，生成固定六行六列的矩阵。面积计算保留精度，仅展示时舍入。

### 页面与任务执行

- 变化检测页的变化前／变化后区域各自选择影像，按完整身份只读关联已有分类结果并展示单期面积；缺面积汇总单独统计，不重跑推理。单位转换唯一实现。
- 变化检测页提供前后期影像、模型选择、执行状态、矩阵及历史记录。
- 长时间识别需有可查询的任务状态；实施前核对项目已有任务执行机制，复用适合的机制。
- 历史结果展示计算时的影像和模型版本信息，避免后续资源更名或更新导致含义不清。

## 实施顺序

1. 核对类别映射、栅格元数据、模型版本识别方式和现有任务／结果表，确定最小存储及接口改动。
2. 扩展单期识别，保存空间分类结果和六类面积，接入前端面积展示。
3. 实现两期结果复用、缺失结果自动计算、网格对齐、共同有效区域统计和矩阵保存。
4. 完成变化检测页面与历史查看入口。
5. 运行相关行为验证及项目必需检查。

## 验收标准

- 已知像素类别和面积的合成栅格能验证六类单期面积；图例隐藏某类不改变统计结果。
- 已知转移关系的两期栅格能验证全部 36 个矩阵元素及对角线；矩阵总面积等于共同有效区域面积。
- 部分重叠、NoData 和有效背景类能被正确区分；无有效重叠给出明确提示。
- 分辨率或坐标系不同的数据能在统一网格正确比较；验证经纬度数据的面积换算，不能只测米制投影。
- 两期缺少识别结果时自动补齐；相同版本结果可复用，影像或权重版本变化后不错误复用。
- 历史记录可再次读取，用户之间结果隔离；失败任务不会留下可复用的半成品。
- 前端单位切换换算正确，矩阵行列方向明确，刷新后仍可从历史读取结果。

## 限制

统计反映模型分类结果，精度受源影像分辨率、推理降采样、分类误差和配准质量影响。首版不包含自动影像配准。
