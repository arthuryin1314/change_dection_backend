# Issue #13 自动统一空间网格验收记录

日期：2026-09-10

## 实现结果

- 同坐标系、同分辨率且像元边界对齐时保留 `DIRECT` 直接读取路径。
- 其他情况使用确定性分析网格：选择地表像元面积较粗的一期作为参考，目标分辨率不细于任一期，类别与有效掩膜均采用最近邻按目标像元中心取样。
- 对齐实现按目标窗口精确换算像元中心并让类别与掩膜共用同一组源索引；未采用带近似阈值的独立 WarpedVRT，以保证窗口大小不改变结果，也避免类别与掩膜落到不同源像元。本机 Rasterio 1.4.4 的 `WarpedVRT(tolerance=0)` 还会触发 `ObjectNullError`，因此保留这条显式采样路径。
- 分析网格、策略版本、计算版本与分析身份摘要随矩阵持久化，并由详情接口原样读取。
- 共同有效区仍为两期有效掩膜的交集；没有共同有效像元时返回 `NO_COMMON_VALID_AREA`，缺少或不可逆的空间元数据时返回 `SPATIAL_METADATA_UNAVAILABLE`。
