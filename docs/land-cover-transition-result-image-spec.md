# 有向多值地物类型转移结果图

## Problem Statement

变化检测目前能够提供前后两个时相的地物识别结果，但用户无法直接看到“哪些像元从一种地物类型变成了另一种地物类型”。仅查看两张分类图需要用户自行对照，容易遗漏变化方向，也无法在图上区分“林地 → 水体”和“水体 → 林地”。

## Solution

在现有变化检测结果中增加一套有向多值地物类型转移结果。系统逐像元比较前时相和后时相的分类结果，只对类别发生变化的像元生成转移值；每一种“前类别 → 后类别”都是独立的转移类型，并由系统在项目范围内分配稳定的内部编码和颜色。

结果页以多值变化色彩图为主，并提供前时相、后时相和变化叠加图作为对照。图例、图像高亮和统计表互相联动。结果同时出现在本次结果、历史详情、下载文件和 PDF 报告中，并提供可视化图片和保留原始数值及 NoData 的栅格结果。

## User Stories

1. 作为变化检测用户，我希望看到一张直接表达类别转移的结果图，以便不必人工对照两张分类图。
2. 作为变化检测用户，我希望“林地 → 水体”和“水体 → 林地”显示为不同转移类型，以便保留变化方向。
3. 作为变化检测用户，我希望每种实际出现的类别转移使用独立颜色，以便在空间上区分不同变化。
4. 作为变化检测用户，我希望结果图保留固定的内部数值，以便结果可以被后续分析和历史比较复用。
5. 作为变化检测用户，我希望同一项目中相同类别转移始终对应相同编码和颜色，以便不同任务的结果可以比较。
6. 作为变化检测用户，我希望图例显示“前类别 → 后类别”，以便直接理解每种颜色代表的变化。
7. 作为变化检测用户，我希望未变化像元不被当作一种变化类型，以便结果只突出真正发生的类别转移。
8. 作为变化检测用户，我希望未变化像元在结果栅格中是 NoData，并在叠加图中透明，以便同时支持分析和底图查看。
9. 作为变化检测用户，我希望未分类、无效或无法可靠配准的像元也被排除，以便这些像元不会产生虚假变化。
10. 作为变化检测用户，我希望结果页突出显示多值变化色彩图，并保留两期分类图和叠加图作为对照，以便核查变化来源。
11. 作为变化检测用户，我希望点击图例中的某种转移类型时，图上高亮该类型，统计表同步定位，以便快速核查单类变化。
12. 作为变化检测用户，我希望看到每种实际出现的转移的像元数和面积，以便量化变化规模。
13. 作为变化检测用户，我希望未变化面积和 NoData 面积作为附加汇总项显示，以便区分没有变化和没有有效数据。
14. 作为变化检测用户，我希望未变化和 NoData 不计入变化总面积，以便变化统计口径清晰。
15. 作为变化检测用户，我希望面积统计继续支持平方米、公顷和平方公里，以便适应不同区域尺度。
16. 作为变化检测用户，我希望单位切换只改变展示，不重新执行识别或变化分析，以便快速查看不同单位。
17. 作为变化检测用户，我希望在本次检测完成后查看结果图，以便立即核查结果。
18. 作为历史结果用户，我希望在历史详情中重新查看相同的结果图和图例，以便复核过去的检测。
19. 作为下载用户，我希望同时获得可视化图片和保留转移值的原始栅格，以便分别用于查看和空间分析。
20. 作为报告阅读者，我希望 PDF 中包含多值变化图、统一图例和对应统计，以便离线检查报告。
21. 作为变化检测用户，我希望两个时相使用同一套类别字典，以便转移名称和编码具有明确含义。
22. 作为变化检测用户，我希望新增类别或类别组合时由系统分配新编码，而已有编码不改变，以便保持历史结果稳定。
23. 作为变化检测用户，我希望两个时相无法可靠对齐时得到明确失败提示，而不是得到一张误导性的变化图。

## Implementation Decisions

- 变化结果采用有向转移语义：每个像元的转移由“前时相类别 → 后时相类别”确定；方向不可交换。
- 未发生类别变化的像元不属于变化结果类型。结果栅格中该区域为 NoData，变化叠加图中该区域透明。
- 两个时相必须使用同一套类别字典和类别编号。项目既有的类别定义继续作为转移名称的来源。
- 系统在项目范围内维护类别对的稳定内部编码和颜色。已有类别对的编码、颜色不得因新任务变化；新增类别对由系统追加分配。
- 用户可见的图例名称统一为 `前类别 → 后类别`。内部编码用于栅格值、图例映射、统计关联和历史复现，不要求用户直接操作编码。
- 结果图和图例只列出本次实际出现的类别转移，不列出未出现的理论组合。
- 未分类、无效、未覆盖和无法可靠配准的区域统一按 NoData 处理，并从转移统计中排除；有效的“其他／背景”仍是合法地物类别。
- 两个时相无法可靠对齐时，任务以失败状态结束，不生成可访问的成功变化结果。系统不自动纠正影像本身的位置偏移。
- 结果页以多值变化色彩图为主图，前时相、后时相和变化叠加图作为对照；页面布局应保留现有变化检测页面的上下文。
- 图例、主图高亮和统计表联动；选择某个转移类型时，只突出该类型对应的像元，并定位对应统计项。
- 统计表按实际出现的转移类型列出像元数和面积；未变化面积、NoData 面积作为附加汇总项展示，但不计入变化总面积。
- 面积沿用系统既有口径：后端以平方米保存，展示支持平方米、公顷和平方公里；单位切换不触发重新识别或重新计算。
- 页面、本次结果下载、历史结果详情和 PDF 报告都使用同一份已完成检测结果及其图例映射，不重新推断或重排类别对。
- 下载同时提供面向查看的可视化图片和保留内部转移值、NoData 及空间参考的原始栅格。
- 现有地物类型转移面积矩阵继续保留其既有语义，包括对角线的未变化面积；本规格中的“变化结果图”仅排除未变化像元，两者统计范围和用途需在页面及报告中明确区分。

## Testing Decisions

- 测试验证用户可观察的结果、持久化后的读取、下载内容和错误行为，不绑定私有函数或内部模块结构。
- 使用已知的前后时相分类栅格覆盖有方向的类别转移，验证 `A → B` 与 `B → A` 是不同值，并验证未变化像元输出为 NoData。
- 验证同一项目中重复生成相同类别对时编码和颜色稳定，新增类别对不会改变已有映射。
- 验证图例只包含本次实际出现的类别转移，名称采用“前类别 → 后类别”。
- 验证无效、未分类、未覆盖和无法可靠配准的区域不进入转移统计；整体无法对齐时不会出现成功结果。
- 验证像元数、面积、未变化汇总和 NoData 汇总的口径，单位切换只改变展示值。
- 验证页面主图、对照图、图例、统计表和高亮联动，以及刷新后历史详情仍能读取同一结果。
- 验证下载的图片与原始数值栅格分别满足查看和分析用途，并保留图例映射、空间参考和 NoData 语义。
- 验证 PDF 使用同一检测结果、同一图例和同一统计口径，不混入其他任务或已替换的影像版本。

## Out of Scope

- 自动影像配准、内容位置偏移纠正和对未配准影像的容错比较。
- 新模型训练、分类体系设计或引入独立的双时相变化检测模型。
- 把未变化像元作为变化类型加入多值变化结果图。
- 三期以上时序变化分析、对象级矢量提取和人工分类修订。
- 让用户手工编辑内部编码或颜色映射。
- 重新定义现有地物类型转移面积矩阵的对角线统计语义。

## Further Notes

- 变化结果的可信度仍受影像分辨率、分类误差和配准质量影响；结果图表达的是分类转移，不等同于真实地物变化的最终判定。
- 结果图、统计表、下载文件和 PDF 必须引用同一份持久化结果快照，避免同一检测在不同出口出现不同编码或统计。
- 本规格只定义用户可观察的行为和验收边界，不规定具体文件路径、端点名称、数据表结构或实现模块。
