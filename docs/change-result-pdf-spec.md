# 变化检测结果 PDF 报告预览与导出

状态：产品需求已确认，作为 PDF 报告功能的正式规格；覆盖前后端，尚未实施。
日期：2026-09-19。

## Problem Statement（问题）

用户已能查看变化检测结果，但无法将前后两期影像、分类图、影像参数、各地物类别面积及地物类型转移面积矩阵汇总为可检查、下载、分享或打印的报告。分别截取页面容易遗漏信息，也可能混淆两期身份、统计范围和面积单位。历史检测结果同样需要可追溯的报告出口。

## Solution（解决方案）

在变化检测页和变化检测历史详情提供「预览 PDF 报告」。用户在生成前选择面积单位，默认公顷；点击按钮生成中文 A4 纵向 PDF 并打开预览。用户翻页、缩放、检查后，点击「导出 PDF」，通过浏览器下载正在预览的同一文件。系统不长期保存 PDF。

报告依次展示报告信息与参数、两期原始影像和分类图、分类面积表及转移矩阵。四幅图均展示完整影像，不带底图，分类图附统一图例。报告绑定一份已完成检测结果，数据和图像不得混入其他结果或替换后的影像版本。

## User Stories（用户故事）

1. 作为检测用户，我希望在变化检测完成后预览 PDF 报告，以便检查本次结果。
2. 作为检测用户，我希望在历史详情预览报告，以便导出过去的结果而无需重新检测。
3. 作为报告阅读者，我希望报告明确区分前期和后期，以便判断变化方向。
4. 作为报告阅读者，我希望看到两期原始影像，以便对照实际场景。
5. 作为报告阅读者，我希望看到两期分类图，以便理解分类面积和转移关系。
6. 作为报告阅读者，我希望每幅图展示完整范围且不带底图，以免页面缩放或底图干扰内容。
7. 作为报告阅读者，我希望分类图使用统一图例，以便正确识别各地物类别。
8. 作为报告阅读者，我希望看到影像名称、采集日期、卫星、分辨率、坐标系和像素宽高，以便了解数据来源和空间特征。
9. 作为报告阅读者，我希望看到模型名称及版本，以便识别本次分析所用模型。
10. 作为报告阅读者，我希望区分检测时间和报告生成时间，以免把重新导出的时间误当作检测时间。
11. 作为报告阅读者，我希望缺失参数明确写为「未记录」，以免将推测当作事实。
12. 作为报告阅读者，我希望看到前后两期各类面积，以便了解两期地物组成。
13. 作为报告阅读者，我希望看到完整的六行六列转移面积矩阵，以便查看类别之间的转化。
14. 作为报告阅读者，我希望明确矩阵行代表前期、列代表后期，对角线代表未变，以便正确解读矩阵。
15. 作为报告阅读者，我希望知道单期面积统计整幅有效区域、矩阵统计共同有效区域，以免误比两者合计。
16. 作为导出用户，我希望默认使用公顷，也能在生成前选择平方米或平方公里，以便适应报告用途。
17. 作为报告阅读者，我希望整份报告的面积单位一致且标注清楚，以免混淆数量级。
18. 作为报告阅读者，我希望极小非零面积不会显示成零，以免遗漏真实的小面积转移。
19. 作为导出用户，我希望先翻页和缩放检查报告，再决定是否导出，以便避免下载未检查的报告。
20. 作为导出用户，我希望下载文件与预览内容完全一致，以免检查后内容又发生变化。
21. 作为导出用户，我希望导出后文件进入浏览器下载流程，以便自行保存和分享。
22. 作为导出用户，我希望系统不长期保存生成的 PDF，以免产生额外的报告管理负担。
23. 作为历史结果用户，我希望新结果保存检测时参数快照，以免之后修改影像资料改变历史报告。
24. 作为历史结果用户，我希望旧结果中无法确认的参数显示「未记录」，以便保留历史真实性。
25. 作为历史结果用户，我希望原图或分类图不可用时明确列出缺失项并阻止生成，以免得到缺图报告。
26. 作为检测用户，我希望导出不会自动重新识别或用新图替代旧图，以免报告偏离原检测结果。
27. 作为导出用户，我希望生成中看到加载状态并避免重复请求，失败后可以重试，以便理解当前进展。
28. 作为导出用户，我希望关闭预览或切换结果后，迟到的响应不会打开错误报告，以免误导出其他结果。
29. 作为报告阅读者，我希望中文、长名称、图例、图片和矩阵在 A4 页面上完整清晰，以便阅读和打印。
30. 作为系统用户，我希望只能获取自己有权访问的结果报告，以便保持现有结果访问边界。

## Implementation Decisions（已确定的行为与约束）

### 结果身份与数据来源

- 两处入口共用同一报告能力，以已完成结果的稳定标识定位内容。未完成或失败的检测不能生成正式报告。
- 面积与矩阵取自已保存结果，不根据截图估算、不重新执行分类或变化分析。
- 新结果保存影像参数的检测时快照。新变化结果复用已有分类时，仍需记录本次输入的参数；复用整个历史变化结果时保留原结果快照。
- 历史字段可信时使用已有值；无法确认的旧参数写「未记录」，不读取当前可变资料冒充历史参数。
- 源影像的坐标系和像素宽高必须描述原始影像，不能误用分类网格或变化分析网格参数。
- 模型版本使用已有可追溯的版本身份并准确标注，不编造版本号。
- 报告生成须验证结果访问权限及两期图像版本；禁止跨用户访问和以新版本图像替代旧版本。

### 内容与格式

- 中文 A4 纵向，内容顺序为「报告信息与参数 → 两期影像及分类图 → 面积表与矩阵」，自动分页。
- 四幅图分别为前期原图、前期分类图、后期原图、后期分类图；完整范围、等比展示、无底图，并明确标记时期和图像类型。
- 参数字段固定为影像名称、采集日期、卫星、分辨率、坐标系、像素宽高；另列模型名称及版本、检测时间、报告生成时间。
- 分类名称、顺序和颜色沿用项目分类定义；转移矩阵与图例保持一致。保留水系、林地、道路、种植土地、房屋建筑、其他／背景六类。
- 未覆盖区域和无效数据不属于「其他／背景」。单期面积与矩阵统计范围不同，不要求其合计相等。
- 后端面积仍以平方米为准；单位选择仅改变报告展示。平方米最多两位小数，公顷和平方公里最多四位小数。
- 正面积小于最小显示量时，平方米显示「<0.01」，公顷／平方公里显示「<0.0001」；真实零显示零。不得先舍入再求和。
- 中文字形、长名称、图片比例、完整矩阵和图例必须清晰，不被裁切或重叠；页数由内容决定。

### 预览、下载与生命周期

- 生成前提供面积单位选择，默认公顷；点击「预览 PDF 报告」后生成并预览，不自动下载。
- 预览支持翻页与缩放；「导出 PDF」下载预览所用同一份文件，不能在点击导出时重新生成。
- 下载进入浏览器下载流程。具体保存位置或是否弹出保存对话框遵循浏览器设置。
- 系统不建立长期 PDF 档案。生成、预览所用临时资源应在结束、取消或失败后释放；再次生成时重新读取同一结果的可信保存数据。
- 生成中展示加载状态并防止重复操作，不要求无依据的百分比进度；关闭或切换结果后忽略过期响应。
- 如需变更单位，应重新生成并预览，不允许下载按钮暗中改变单位。

### 缺失与失败

- 原图、分类图或必要掩膜不可用，或内容版本不匹配时，阻止生成并明确列出受影响的时期和资源。
- 参数缺失与图像缺失区别处理：参数写「未记录」允许生成，必需图像缺失拒绝生成。
- 面积或矩阵不完整时不能伪造零值或输出正式残缺报告；明确说明结果不可用于报告。
- 生成失败允许用户重试，但不因此自动重跑检测、恢复文件或替换输入。

### 技术选型边界

- 优先复用已有结果读取、身份校验、分类渲染、面积换算和前端认证请求能力。
- 本规格不锁定 PDF 生成库、预览组件、API 路径、数据库字段名称或模块文件布局。
- open-file-viewer 仅为用户提供的可选参考，不是必须采用的依赖。此前提出的 ReportLab、PDF.js 等属于技术建议，不作为已获用户批准的实现决定。

## Testing Decisions（测试与验收）

测试观察用户可见行为与公开接口结果，避免断言私有函数调用顺序、组件内部变量或实现细节。优先在现有边界扩展，以下是实施时的验收建议，并非本轮已执行的测试。

### 测试边界与先例

- 主要边界为「选择已完成结果 → 预览 PDF → 导出」的页面流程，两处入口采用相同验收用例。
- 后端在现有结果／历史接口集成测试边界验证鉴权、快照、图像版本和 PDF 响应。参考项目已有变化结果路由、PostgreSQL 集成和冻结输入测试方式。
- 前端参考已有变化会话、历史会话、影像预览和身份校验测试，重点验证切换、取消、错误展示及历史一致性。
- PDF 文件本身作为独立输出验收：解析文本和页面信息后，实际渲染逐页检查中文、图片、图例、表格及分页。只通过文本提取不能证明版面正确。

### 验收条件

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| AC-01 | 当前变化检测已成功 | 可通过「预览 PDF 报告」生成对应结果的报告 |
| AC-02 | 打开可用历史结果 | 可生成该历史结果报告，无需重新检测 |
| AC-03 | 结果未完成、失败或无访问权限 | 无法生成正式报告，服务端也拒绝越权访问 |
| AC-04 | 生成正常报告 | 包含完整四图、指定参数、模型与时间信息、两期面积和 6×6 矩阵 |
| AC-05 | 改变页面地图缩放或底图 | 报告仍显示完整影像且不带底图 |
| AC-06 | 两期范围不同 | 单期面积与矩阵分别沿用各自统计范围，并明确说明 |
| AC-07 | 切换三种面积单位 | 全报告换算与标注一致，原始结果不改变 |
| AC-08 | 输入真实零及极小正面积 | 零与低于显示阈值的非零数值清晰区分 |
| AC-09 | 新结果生成后修改影像业务资料 | 报告仍使用检测时参数快照 |
| AC-10 | 旧结果缺参数 | 显示「未记录」，不冒用当前资料 |
| AC-11 | 原图删除、替换或分类资源缺失 | 拒绝生成，列出缺失项，不输出缺图 PDF |
| AC-12 | 面积或矩阵不完整 | 明确失败，不补零或自动重新检测 |
| AC-13 | 翻页和缩放 | 可检查所有页面，图像与文字正常显示 |
| AC-14 | 点击「导出 PDF」 | 浏览器下载文件，下载内容与预览文件字节一致 |
| AC-15 | 生成中重复点击、关闭或切换结果 | 不重复生成有效请求，过期响应不污染当前预览 |
| AC-16 | 请求失败后重试 | 错误可理解，可重新发起，不下载残缺文件 |
| AC-17 | 长中文名称及不同长宽比影像 | A4 纵向自动分页，无乱码、重叠、拉伸或裁切，矩阵完整可读 |
| AC-18 | 正常关闭、取消或生成失败 | 临时资源释放，无长期 PDF 记录或残留档案 |
| AC-19 | 新变化结果复用旧分类 | 仍保存本次输入参数；直接复用旧变化结果则不篡改旧快照 |

## Out of Scope（范围外）

- 单期识别报告、批量导出、Word／Excel 导出、自定义报告模板或在线编辑报告。
- 长期 PDF 存档、分享链接、邮件发送、自动定时导出。
- 新增识别算法、重新计算面积口径、自动纠正影像配准、额外分析结论。
- 为缺失历史图像自动恢复、重跑分类或使用新图替代旧图。
- 强制引入 open-file-viewer 或建设通用多格式文件预览平台。
- 本次发布仅登记需求，不执行功能实现、依赖安装、数据库变更、提交、推送、服务重启或部署。
